# 🖤 Grunge Wallpaper

A manga-inspired wallpaper website with a comic-style aesthetic, bold visuals, and a dark grunge atmosphere. Built using HTML, CSS, and JavaScript, the website offers a creative space to explore and interact with wallpapers.

## ✨ Features

- 🎨 Manga and comic-inspired UI
- 🖼️ Interactive wallpaper gallery
- 🔍 Search functionality to find wallpapers
- ❤️ Like functionality for favorite wallpapers
- 👁️ Wallpaper preview
- 🌑 Dark grunge-inspired visual design
- 💻 Built with pure HTML, CSS, and JavaScript

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, layouts, animations, and visual effects
- **JavaScript** – Interactive features and functionality

## 🚀 Getting Started

Want to explore the project locally?

**1. Clone the repository**

```bash
git clone https://github.com/s1ay3/grunge-wallpaper.git
```

**2. Navigate to the project folder**

```bash
cd grunge-wallpaper
```

**3. Run the website**

Open `index.html` in your browser or use the Live Server extension in VS Code.

## 🎯 Project Objective

The objective of this project is to combine manga-inspired comic aesthetics with a modern wallpaper browsing experience, creating a visually distinctive and interactive website using fundamental frontend technologies.
